This is 2nd assignment of cloud computing.

Tasks to Perform 
Step 1: Create a Repository

Create a new Git repository and add a text file containing an initial message.

Step 2: Create a Feature Branch

Create a separate branch to represent another developer's work.

Step 3: Modify the File in the Feature Branch

Update the content of the file and save the changes.

Step 4: Return to the Main Branch

Switch back to the Main Branch.

Step 5: Modify the Same Content

Update the same line or section of the file with a different value than the one used in the Feature Branch.

Step 6: Attempt to Merge

Merge the Feature Branch into the Main Branch.
Observe how Git reports a merge conflict because both branches modified the same content differently.


Step 7: Analyze the Conflict

Open the affected file and examine the conflict markers added by Git.
Understand:

Which change belongs to the Main Branch.

Which change belongs to the Feature Branch.

Why Git could not merge them automatically.



Step 8: Resolve the Conflict

Manually edit the file and decide how the final content should appear.
You may:

Keep the Main Branch version.

Keep the Feature Branch version.

Combine both versions.



Step 9: Complete the Merge

After resolving the conflict, mark the file as resolved and finalize the merge.

Step 10: Review the Repository History

Verify that the merge has been completed successfully and that both branches' work is reflected in the project history.
